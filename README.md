# Customer_shoping_DataAnalysis
Customer Shopping Behavior Analysis project using Python, PostgreSQL, and Power BI to clean, analyze, and visualize customer purchasing patterns, customer segmentation, product performance, and business insights through an interactive dashboard.

# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data to uncover valuable business insights. The analysis combines **Python**, **PostgreSQL**, and **Power BI** to clean, analyze, and visualize customer purchasing patterns, helping businesses make data-driven decisions.

The dataset contains **3,900 customer purchase records** with **18 features**, including customer demographics, purchase details, subscription status, discounts, and review ratings.

---

## 🎯 Objectives

* Analyze customer purchasing behavior.
* Identify high-value customer segments.
* Compare spending patterns across demographics.
* Evaluate the impact of discounts and subscriptions.
* Build an interactive Power BI dashboard for business insights.
